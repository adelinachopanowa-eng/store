# Прогрестрейд · Складова програма за скрап

Уеб приложение за управление на складови наличности от скрап по материали със
**средно претеглена цена**. Изградено с Next.js + Supabase (Postgres).

## Функционалности

- **Доставки** — доставчик, нетно (чисто) количество, незадължителна изкупна
  цена (може да се добави по-късно), начин на плащане (брой/банка) и статус
  „платено". Една доставка може да се разпределя по няколко материала —
  процентно или в тонове.
- **Материали** — всеки материал води собствена средно претеглена цена.
- **Продажби / експедиции** — изписване на стока по средна себестойност с
  изчисление на печалба. Продажната цена може да се остави празна и да се
  допълни по-късно.
- **Редакция** — доставки и продажби могат да се редактират (вкл. добавяне на
  цена впоследствие) без да се нарушава дневникът.
- **Пресортиране** — прехвърляне между материали с коректно преизчисляване на
  средната цена (стойността се движи заедно с количеството).
- **Ad-hoc въвеждане** — нов доставчик/материал в движение, но с
  база данни за бързо избиране.
- **Табло** — наличност, средна цена и стойност по материали.
- **История** — неизменим дневник (ledger) на всички движения.
- **Справки** — складови наличности, доставки за период, продажби и печалба,
  неплатени документи. Експорт в CSV (отваря се в Excel).

## Архитектура

Ядрото е **счетоводен дневник** `wh_ledger`: всяко движение е неизменим запис
със знаково количество и стойност. Средната цена на материал =
`сума(стойност) / сума(количество)`. Така историята е пълна, а средната цена
винаги е математически коректна — включително при продажби и пресортирания.

Атомарните операции са реализирани като Postgres функции (RPC):
`wh_record_delivery`, `wh_record_sale`, `wh_record_transfer`,
`wh_update_delivery`, `wh_update_sale` — гарантират консистентност и проверки
(напр. недостатъчна наличност, сбор на материалите).

### Таблици (схема `public`, префикс `wh_`)

| Таблица | Предназначение |
|---|---|
| `wh_suppliers` | Контрагенти (доставчици/клиенти) |
| `wh_materials` | Материали (видове скрап) |
| `wh_ledger` | Неизменим дневник на движенията |
| `wh_deliveries` / `wh_delivery_allocations` | Доставки и разпределение по материали |
| `wh_sales` | Продажби/експедиции |
| `wh_transfers` | Пресортирания |
| `wh_material_balances` (view) | Наличност + средна цена + стойност |
| `wh_history` (view) | Обединена история за одит |

Складовият модул е самостоятелен и **не променя** съществуващите таблици на
проекта Прогрестрейд.

## Стартиране

```bash
npm install
cp .env.example .env.local   # попълнете URL и ключ от Supabase
npm run dev
```

Отворете http://localhost:3000

## Деплой

Готово за Vercel. Добавете променливите `NEXT_PUBLIC_SUPABASE_URL` и
`NEXT_PUBLIC_SUPABASE_ANON_KEY` в настройките на проекта.
